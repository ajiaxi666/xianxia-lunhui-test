# 仙途·轮回 · 公开测试版

仙侠题材「增量挂机 × Roguelike」游戏原型（three.js 3D 版）。

## 在线试玩

**▶ 打开即玩，无需安装**（Chrome / Edge 最新版，手机也可访问）

## 玩法简介

1. 点击金色圆盘「吐纳」得灵石，灵气自动转化为修为
2. 升级洞府（聚灵阵/御剑诀）提升产出与战力
3. 修为攒满突破境界；跨大境界渡天劫——看准成功率再上
4. 每破一大境界，小人的道袍/光环/披风/飞剑都会变化
5. 寿元耗尽或渡劫失败即「兵解」，按本世成就结算道果
6. 在轮回殿用道果永久强化灵根，再入轮回

目标：在寿元耗尽前突破九境，渡过终极天劫，飞升成仙。

## 反馈方式

游戏内右上角有「反馈」按钮（或直接提 [GitHub Issue](https://github.com/ajiaxi666/xianxia-lunhui-test/issues/new)），提交时会自动带上你的游戏状态（境界/寿元/战力），方便我们复现问题。任何 Bug、平衡感受、玩法建议都欢迎。

## 本地运行

下载本仓库后双击 `index.html` 即可（需与 `assets/` 同目录）。存档在浏览器 localStorage。
